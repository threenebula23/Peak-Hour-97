## 7. Дельты v3.1: TCP, UDP, темп и UI

Короткая матрица под текущую реализацию; числа — из `data/balance.json` и
`scripts/core/hour_director.gd`, а не из исторических таблиц выше. Полный
набор + parse-check запускается через `scripts/run_all_tests.sh` /
`.ps1`; список в runner — источник истины, счёт наборов здесь не
фиксируется. Core-наборы (`test_hour`, `test_economy`, `test_save`,
`test_slots`, `test_controller`, `test_integration`, `test_fuzz`,
`test_full_playthrough`, `test_shop`, `test_shop_modal`) обновлены и зелёные;
UI-наборы (`test_main_*`, `ui_smoke`) прогоняются отдельно.
