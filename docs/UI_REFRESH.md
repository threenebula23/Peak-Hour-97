# UI_REFRESH — UI v2 «Kaleidos»

Статус: **реализовано** в v1.2. Это короткая карта текущего UI, а не план
интеграции. Стиль: тёплая бумага, тонкие 1 px контуры, мягкие тени,
скругления 3–4 px, бирюзовый акцент, меньше визуального шума.

## Окно и масштаб

- Окно **1600×900**, логический viewport **1280×720**.
- `stretch/mode = canvas_items`, `aspect = keep`, `scale_mode = fractional`.
- Шрифты: Handjet (текст), Press Start 2P (логотип/цифры).
- Всё рисуется кодом; внешних текстур UI нет.

## Ключевые сценарии

- **Магазин:** виден только в подготовке и после часа 1; в час скрыт.
  Каталог перечитывается при открытии. Поиск/щит скрыты до мета-наград
  `survive_hour_3` / `survive_hour_5`.
- **Поиск:** после открытия в окне «ФАЙЛЫ» появляется поле «поиск по имени…»;
  фильтрует текущую папку, заголовок показывает «N ИЗ M ОБЪЕКТОВ».
- **Приём:** скролл для 5–8 пакетов; после приёма/перемещения текущая папка и
  дерево обновляются автоматически.
- **Папки:** имена из `names_ru.json`, уникализируются в секции (`Имя`,
  `Имя 2`); пустые папки можно удалять.
- **Attached:** зелёная галочка у файла и слота запроса.
- **Туториал:** БАЙТ и короткие подсказки в первом часе; без пошагового
  сценария.
- **Настройки:** кнопка на главном экране открывает рабочую модалку.
- **Магазин без X:** закрытие только «Закрыть» или `Esc`.
- **Calm-фон:** при включённом «Спокойном фоне» Backdrop рисует плоскую
  `PAPER` без dither; серый `#C0C0C0` не появляется.
- **Итоги забега:** строка «ОТКРЫТО: …» показывает полученные мета-награды;
  `Esc` ведёт в главное меню, без soft-lock.
- **Drag пакета на слот:** перетаскивание пакета на TCP-слот запускает
  настоящее соединение, а не только визуальный перенос.

## VHS-эффект главного меню

Тонкий CRT/VHS-слой есть **только на главном меню** (`shaders/vhs.gdshader` +
`scripts/ui/vhs_overlay.gd`). Полноэкранный `ColorRect` с canvas_item-шейдером
читает готовый кадр через `hint_screen_texture`.

Ключевое — **native-res**: эффект считается в физических пикселях окна
(`FRAGCOORD`/`SCREEN_PIXEL_SIZE`). При 1920×1080 скан-линии идут ровно каждые
2 px, без блоков и banding; логика UI при этом остаётся 1280×720
(`stretch/mode = canvas_items`), но VHS не растягивает 1280-текстуру.

- screen texture сэмплится с линейной фильтрацией 1:1. Identity-проверка
  при 1920×1080: diff в области текста = 0, то есть картинка не мылится;
- хроматика ≤0.0003 UV (~0.6 px у края кадра), зелёный канал не сдвигается —
  буквы не двоятся;
- полоса меняет только яркость и не двигает изображение, поэтому текст
  под ней не «плывёт».

Параметры (`VhsOverlay` / шейдер):

| Параметр | Значение | Смысл |
| --- | --- | --- |
| `intensity` | **0.40** (макс. 0.55) | общая сила слоя |
| `scanline_step` | 2 физ. px | тонкие ровные скан-линии |
| `scanline_strength` | 0.06 | затемнение ≈2.4% при intensity 0.40 |
| `aberration` | 0.0003 UV | мягкая хроматика, без двоения |
| `grain` | 0.025, 2 Гц | слабое зерно, без мерцания |
| `vignette` | 0.11 | затемнение к краям кадра |
| `band` | 0.04, ~18 с на проход | редкая полоса, только яркость |

Слой — последний ребёнок `MainMenu`, `mouse_filter = IGNORE`,
`process_mode = ALWAYS`. Модалки (настройки, подтверждение) — отдельные
соседи в `modal_root`, рисуются поверх и **не** фильтруются.

В HEADLESS материал не создаётся, слой скрыт — тесты не тормозят.

**Как отключить:**

- настройки → «ЭКРАН» → галочка «VHS-эффект» (применяется по «Подтвердить»,
  хранится в `settings`);
- кодом: `main_menu.set_vhs_enabled(false)` или `main_menu.vhs.set_enabled(false)`;
- сила эффекта: `main_menu.vhs.intensity` (0…0.55).
