# UI_REFRESH — UI v3 «Kaleidos»

Статус: **реализовано** в v3. Это короткая карта текущего UI, а не план
интеграции. Стиль: тёплая бумага, тонкие 1 px контуры, мягкие тени,
скругления 3–4 px, бирюзовый акцент, меньше визуального шума.

## Окно и масштаб

- Окно **1920×1080**, логический viewport **1280×720**.
- `stretch/mode = canvas_items`, `aspect = keep`, `scale_mode = fractional`.
- Шрифты: **Golos Text** (тело текста), **Press Start 2P** (логотип/цифры).
  Handjet и Pixelify Sans в теме не используются (D51).
- Типографическая шкала: **11 / 13 / 17 / 26 px**. Подписи файлов — 12–16 px
  по размеру клетки.
- Почти всё рисуется кодом; внешняя графика — только пиксельные иконки
  `art/icons/*.png` (32×32, `nearest`).

## Ключевые сценарии

- **Магазин:** виден только в подготовке и после часа 1; в час скрыт.
  Каталог перечитывается при открытии. Поиск/щит скрыты до мета-наград
  `survive_hour_3` / `survive_hour_5`.
- **Поиск:** после открытия в окне «ФАЙЛЫ» появляется поле «поиск по имени…»;
  фильтрует текущую папку, заголовок показывает «N ИЗ M ОБЪЕКТОВ».
- **Приём:** скролл для 5–8 пакетов; после приёма/перемещения текущая папка и
  дерево обновляются автоматически.
- **Папки:** имена из `names_ru.json`, уникализируются в секции (`Имя`,
  `Имя 2`); пустые папки можно удалять. Сетка растёт до **9×6**.
- **Запросы:** карточка 400×128 показывает имена 1–4 обязательных файлов
  сеткой 2×2. Наведение на чип показывает полное имя строкой внутри карточки
  и в tooltip; потерянный файл — красный чип с «ПОТЕРЯН». Прогноз
  `МИНИ-ИГРА: … · Tn` и `СЛОЖНОСТЬ: N` считается по обязательным файлам ещё
  до прикрепления.
- **TCP:** кнопка `СОЕДИНИТЬСЯ` открывает полоску соединения 640×240
  (3 попадания, 440/340/280 px/с). После успеха сразу открывается мини-игра
  отправки, протокол блокируется. UDP идёт сразу в мини-игру.
- **Attached:** зелёная галочка у файла и чипа запроса.
- **Пустая отправка:** плашка «ЖДЁМ ЗАПРОС» и подсказка «Следующий запрос
  ~N с» / «Все запросы часа выданы» / «Нет свободных файлов для запроса».
- **Туториал:** 5 шагов (пакет → прикрепление → TCP → мини-игра → SLA/атаки),
  пульсирующая рамка вокруг цели, кнопка «ДАЛЕЕ», сохранение
  `tutorial_done`, повтор из меню кнопкой «ОБУЧЕНИЕ».
- **Настройки:** кнопка на главном экране открывает рабочую модалку.
- **Магазин без X:** закрытие только «Закрыть» или `Esc`.
- **Calm-фон:** при включённом «Спокойном фоне» Backdrop рисует плоскую
  `PAPER` без dither; серый `#C0C0C0` не появляется.
- **Итоги забега:** строка «ОТКРЫТО: …» показывает полученные мета-награды;
  `Esc` ведёт в главное меню, без soft-lock.
- **Слоты:** полоса подписана «СЛОТЫ» — слоты общие для приёма и отправки.
- **Подписи занятости диска** в панели файлов и подвале сетки больше нет:
  остаётся только счётчик файлов/клеток.
- **Тосты:** сверху по центру (400 px, x = 440…840), стопкой вниз от `y=44`;
  панель ОТПРАВКА не перекрывают.
- **Подписи файлов:** 3 / 2 / 1 строки при клетке ≥88 / 72–87 / <72 px,
  кегль 12–16 px с авто-уменьшением до 11 px, полное имя — в tooltip.
- **Чипы запросов:** имя 10 px (9 px, только если это позволяет показать имя
  целиком); при наведении — полное имя и папка в строке карточки и tooltip.

## Мини-игры

- Общая шапка 640×360: две строки — название и цель, полоса прогресса в
  шапке, акцентная линия у цели.
- `dots` — непрерывная линия протяжкой; быстрое движение сэмплируется, а
  недопустимые клетки игнорируются молча.
- `ПРОПУСТИТЬ`/`СДАТЬСЯ` требует двух кликов: первый взводит кнопку, второй
  подтверждает.
- Результат: имя игры, `q%`, полоса качества, вердикт, детали, `ПРОДОЛЖИТЬ`;
  `Esc` = продолжить.
- Подсказки атак — внутри окна, в нижней полосе, без обрезки.

## VHS-эффект главного меню

Тонкий CRT/VHS-слой есть **только на главном меню** (`shaders/vhs.gdshader` +
`scripts/ui/vhs_overlay.gd`). Полноэкранный `ColorRect` с canvas_item-шейдером
читает готовый кадр через `hint_screen_texture`.

Ключевое — **native-res**: эффект считается в физических пикселях окна
(`FRAGCOORD`/`SCREEN_PIXEL_SIZE`). При 1920×1080 скан-линии идут ровно каждые
2 px, без блоков и banding; логика UI при этом остаётся 1280×720
(`stretch/mode = canvas_items`), но VHS не растягивает 1280-текстуру.

- screen texture сэмплится с линейной фильтрацией 1:1. Identity-проверка
  при 1920×1080: diff в области текста = 0, то есть картинка не мылится;
- хроматика ≤0.0003 UV (~0.6 px у края кадра), зелёный канал не сдвигается —
  буквы не двоятся;
- полоса меняет только яркость и не двигает изображение, поэтому текст
  под ней не «плывёт».

Параметры (`VhsOverlay` / шейдер):

| Параметр | Значение | Смысл |
| --- | --- | --- |
| `intensity` | **0.40** (макс. 0.55) | общая сила слоя |
| `scanline_step` | 2 физ. px | тонкие ровные скан-линии |
| `scanline_strength` | 0.06 | затемнение ≈2.4% при intensity 0.40 |
| `aberration` | 0.0003 UV | мягкая хроматика, без двоения |
| `grain` | 0.025, 2 Гц | слабое зерно, без мерцания |
| `vignette` | 0.11 | затемнение к краям кадра |
| `band` | 0.04, ~18 с на проход | редкая полоса, только яркость |

Слой — последний ребёнок `MainMenu`, `mouse_filter = IGNORE`,
`process_mode = ALWAYS`. Модалки (настройки, подтверждение) — отдельные
соседи в `modal_root`, рисуются поверх и **не** фильтруются.

В HEADLESS материал не создаётся, слой скрыт — тесты не тормозят.

**Как отключить:**

- настройки → «ЭКРАН» → галочка «VHS-эффект» (применяется по «Подтвердить»,
  хранится в `settings`);
- кодом: `main_menu.set_vhs_enabled(false)` или `main_menu.vhs.set_enabled(false)`;
- сила эффекта: `main_menu.vhs.intensity` (0…0.55).

## Проверки

```bash
godot --headless --path . --script scripts/ui/ui_smoke.gd
bash scripts/run_all_tests.sh
```

`ui_smoke` и остальные наборы — см. `scripts/run_all_tests.sh` и `tests/`
(число проверок/наборов может меняться между волнами). Скриншоты для страницы —
в `docs/screenshots/`; после смены UI их нужно переснять под текущий вид
(окно 1920×1080, логический кадр 1280×720).
