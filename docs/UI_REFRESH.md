# UI_REFRESH — UI v2 «Kaleidos»

Статус: **реализовано** в v1.2. Это короткая карта текущего UI, а не план
интеграции. Стиль: тёплая бумага, тонкие 1 px контуры, мягкие тени,
скругления 3–4 px, бирюзовый акцент, меньше визуального шума.

## Окно и масштаб

- Окно **1600×900**, логический viewport **1280×720**.
- `stretch/mode = canvas_items`, `aspect = keep`, `scale_mode = fractional`.
- Шрифты: Handjet (текст), Press Start 2P (логотип/цифры).
- Всё рисуется кодом; внешних текстур UI нет.

Контур — 1 px `Theme90.BORDER`; тень только у карточек/панелей/модалок.
Радиус: 3 px — кнопки/строки, 4 px — карточки/панели, 6–8 px — модалки.
Кегли: 10 / 12 / 16 / 24.

## Ключевые сценарии

- **Магазин:** виден только в подготовке и после часа 1; в час скрыт.
  Каталог перечитывается при открытии. Поиск/щит скрыты до мета-наград
  `survive_hour_3` / `survive_hour_5`.
- **Поиск:** после открытия в окне «ФАЙЛЫ» появляется поле «поиск по имени…»;
  фильтрует текущую папку, заголовок показывает «N ИЗ M ОБЪЕКТОВ».
- **Приём:** скролл для 5–8 пакетов; после приёма/перемещения текущая папка и
  дерево обновляются автоматически.
- **Папки:** имена из `names_ru.json`, уникализируются в секции (`Имя`,
  `Имя 2`); пустые папки можно удалять.
- **Attached:** зелёная галочка у файла и слота запроса.
- **Туториал:** БАЙТ и короткие подсказки в первом часе; без пошагового
  сценария.
- **Настройки:** кнопка на главном экране открывает рабочую модалку.
- **Магазин без X:** закрытие только «Закрыть» или `Esc`.
