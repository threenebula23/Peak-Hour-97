# Архитектура (черновик)

Каркас, без реализации. Ниже — договорённости, чтобы код писался в одном стиле.

## Поток сцен

```
Main.tscn (меню)
   └─ Prep.tscn    — подготовка к смене (TODO)
   └─ Hour.tscn    — час пик, HUD + мини-игры (TODO)
   └─ Results       — итоги смены (TODO, модалка или сцена)
```

Переходы — только через автолоад `Game` (сигнал `state_changed`), сцены не
переключают друг друга напрямую.

## Автолоады

| Имя | Скрипт | Назначение | Статус |
| --- | --- | --- | --- |
| `Game` | `scripts/autoload/game.gd` | состояния, переходы, сброс забега | заглушка |
| `Data` | `scripts/autoload/data.gd` | чтение `res://data/*.json`, строки | заглушка |
| `Audio` | `scripts/autoload/audio.gd` | SFX/музыка, громкости | заглушка |
| `Rng` | `scripts/autoload/rng.gd` | сид забега, детерминизм | заглушка |

Правило: автолоады не знают о конкретных сценах; сцены не хранят глобальное состояние.

## Данные

- `data/balance.json` — числа (длительность часа, кривая спавна, очки).
- `data/strings_ru.json` — ключи UI (ru). Позже можно перейти на `.translation`/CSV.
- `data/names_ru.json` — пул имён посетителей.

Всё читается через `Data`, значения по умолчанию — в `scripts/core/constants.gd`.

## Договорённости по коду

- GDScript, `snake_case` для файлов и функций, `PascalCase` для узлов/сцен.
- Комментарии и UI-тексты — на русском, идентификаторы — на английском.
- Никаких `class_name` в заглушках (чтобы не плодить глобальные символы раньше времени).
- Мини-игры наследуют `scripts/minigames/minigame_base.gd` и не лезут в HUD напрямую.

## Ограничения платформы (web, no threads)

- Не использовать `Thread`, `WorkerThreadPool`, блокирующее IO в кадре.
- Аудио: `AudioStreamOggVorbis`/`WAV`; большие треки — стримингом.
- Размер `.pck` держать небольшим: текстуры — nearest, без мип-цепочек там, где не нужны.
