# AI_REPORT — PEAK HOUR 97 (v3.0)

## 1. Инструменты и модели

Работа велась в **OpenCode** с субагентами (backend, frontend, designer,
test-writer, explorer, feis-regulator, oracle):

| Модель | Роль |

| **DeepSeek V4.1 Flash** | оркестратор, основной код Godot/GDScript |

74–90 с, комментарий в MR, без мержа.

## 2. Что изменилось в v3.0

- **Запросы:** 1–4 **конкретных именованных файла** вместо анонимных слотов;
  имена на карточке 2×2, прикрепление по точному `file_id`, «ПОТЕРЯН» для
  пропавшего файла, жёсткая резервация. Новые `request_mix` H1–H9 и
  `request_cap`; H1-затравка и анти-голодание.
- **TCP:** возвращена полоска соединения (3 попадания, 440/340/280 px/с,
  формула зоны, промах −4 SLA / 8 с, Esc 0 SLA / 4 с). TCP платит ×1.15,
  UDP — ×0.85 и передаёт ×0.8.
- **Мини-игры:** 6 отправки + 4 атаки; игра с соединением проводов удалена;
  у отправки 3 ступени (старые T2–T4), у атак 4. Выбор — по сумме
  коэффициентов и таблице `rank_games` на 27 достижимых сумм.
- **Магазин:** 8 лотов, дерево **8 085 $**, SLA до **220**, ускорение ×0.90,
  щит с 70 % награды, папки до 9×6, новая папка 180 $ (в v3.1 — 9 лотов и
  8 825 $, см. §10).
- **UI:** Golos Text для тела текста, Press Start 2P только для логотипа и
  цифр; шкала 11/13/17/26; пиксельные иконки `art/icons/`; карточка запроса
  400×128 с сеткой файлов и прогнозом; пустое состояние отправки; «СЛОТЫ».
- **Туториал:** 5 шагов с событийными триггерами, пульсирующие рамки,
  «ДАЛЕЕ», сохранение `tutorial_done`, повтор из главного меню.
- **Документация:** GDD/DECISIONS/README/ITCH_PAGE/UI_REFRESH/ASSETS
  переписаны под фактические числа v3; старые решения помечены, а не удалены.

## 4. Приём: «враждебный критик»

Промпт просил быть враждебным критиком: «найди блокеры, из-за которых
прототип нельзя собрать; не хвали». Главный дефект v2 — **B4**: выбор
мини-игры по `S−1` давал дыры и недостижимые строки. В v3 выбор перестроен:

    ACHIEVABLE_SUMS = [1..22, 24, 25, 26, 28, 32]   # 27 сумм для 1–4 файлов
    rank  = index of S in ACHIEVABLE_SUMS
    tier  = T1 при rank 0–7, T2 при 8–13, T3 при 14–26
    id    = RANK_GAMES[rank]                        # фиксированная таблица

Все 6 игр достижимы в каждой из 3 ступеней; S=32 → video/T3. Дополнительно
закрыты: H1-голодание запросов (анти-голодание + seed-файл), потерянные
required-файлы (подстановка того же типа), неоднозначность TCP-протокола
(блокировка после соединения). M16 (бесплатное уничтожение неприкреплённого
файла) сохранён, но файл, закреплённый за запросом, удалить нельзя.

## 5. Что сделано без ИИ

Идея, логлайн, исходная спецификация, ключевые решения (1997 год, 9 часов,
4 атаки, экономика, тон 90-х) и финальная приёмка — человеком, автором
проекта. ИИ не придумывал игру: он помогал формулировать, писать код,
считать баланс и искать противоречия.

## 8. Известные отклонения

- `ПРОПУСТИТЬ` даёт `q=0`; `quality = 0.5`, то есть половина
  quality-множителя, а не нулевая выплата. Осознанно.
- `speed` выплаты фиксируется на старте отправки, пока таймер был заморожен
  мини-игрой; быстрый игрок видит ≈1.0.
- Лимит папок 6, новая папка 180 $.
- Бесплатное уничтожение любого неприкреплённого файла в подготовке
  (review M16); файл, закреплённый за запросом, не удаляется.
- Деньги атак масштабируются по часу `max(0.75, hour/3)` (review M8).
- H2 теоретически может выдать T2-запрос из трёх фото (S12); на практике
  кривая H2 остаётся почти полностью T1.
- Расход магазина **44,9 %** — ниже проектной полосы 55–65 %; это известное
  отклонение, не влияющее на exit code.

## 9. Ограничения

Туториал автоматически запускается только в первом часу первого забега;
повтор — из главного меню. Web-save — IndexedDB; плейтест, громкость и

## 10. Изменение v3.1: TCP-модель, UDP-лот и шрифты

Короткая запись о текущей волне — без переписывания истории выше.

- **TCP-соединение — отдельная сущность `TcpConnection`.** Оно живёт в
  `HourDirector.active_connections`, занимает out-слот и хранит только клиента,
  IP и `request_id`. До соединения файлы в запрос не прикрепляются (drag
  отклоняется, backend режет). Кнопка `ПОДКЛЮЧИТЬСЯ` справа снизу запускает
  полоску; успех больше не открывает мини-игру отправки.
- **Слот после отправки.** Успешная TCP-отправка удаляет запрос, но файлы
  **не расходует**: они возвращаются в папку и доступны новым запросам. Слот
  остаётся занятым (idle) до ручного `ОТКЛЮЧИТЬ`. Отключение
  мгновенное; во время передачи оно прерывает её без выплаты и без расхода
  файлов. `reject`/`timeout`/конец часа освобождают слоты. Слоты общие,
  `1 + slot_level` (макс. 5); TCP может занять единственный слот и
  заблокировать приём — это осознанно.
- **UDP-риск.** Новый лот `lot_udp` («UDP-повторитель», 4 уровня, цены
  60/120/210/350) поднимает шанс с **40 %** до **80 %** шагом **+10 %**.
  Ролл — в конце передачи: успех даёт обычную выплату UDP ×0.85; провал —
  **−3 SLA**, без денег, файлы остаются, запрос жив, повтор через **4 с**,
  слот освобождается, streak сбрасывается. Всего лотов **9**, дерево
  **8 825 $**.
- **Шрифты.** Тело — **Kechusilka Regular** (нормализован под Golos,
  x-height 0.530 em) с fallback **Golos Text**; крупный текст — **DisplayOTF**
  (wordmark 46, «ПОБЕДА/ПОРАЖЕНИЕ» 34, титлбар 14, «РЕЗУЛЬТАТ» 18); цифры и
  счётчики — **Press Start 2P**. Шкала 11/13/17/26.
- **Документация:** обновлены `docs/GDD.md`, `docs/DECISIONS.md` (D53–D61),
  `docs/UI_REFRESH.md`, `docs/IMPLEMENTATION.md`, `docs/TEST_PLAN.md`,
  `docs/ITCH_PAGE.md` и `README.md`. `ASSETS.md` не менялся — шрифтовые
  лицензии уже зафиксированы там.
- **Проверки:** полный набор + parse-check; core-наборы обновлены и зелёные;
  UI-наборы (`test_main_*`, `ui_smoke`) ещё идут. `tests/SIM_BALANCE_REPORT.md`
  отражает текущий `data/balance.json`: **7 205 $**, магазин **44,9 %**,
  **0/240** поражений, exit **0**.

## 11. v3.1: темп, каталог файлов и «ЖАРА»

Текущая волна; история выше не переписана.

- **Длительность:** часы **120 / 150 / 180 / 210 / 240 / 270 / 300 / 330 /
  360 с** (`120 + 30×(h−1)`), забег **36 минут** + подготовка. H1
  `income_target` — **100 $**. Окно спавна — **75 %** часа.
- **Файлы:** успешная отправка не удаляет файл; он остаётся в папке и снова
  доступен пулу запросов. Общего лимита на забег нет; `hours[].files`
  (**6,6,7,8,9,9,10,10,10**) — скорость, не жёсткий cap. Интервал —
  `spawn_window / files`, переноса между часами нет (carry = 0); папки
  докупаются, к финалу ~**5–6**.
- **Запросы:** `request_cap` удалён. Темп — `send_interval`
  (**20,24,18,24,24,24,24,24,24**), лимит — только `active_requests` +
  cutoff последних **10 с**. Анти-голодание — только первый запрос часа;
  требования выбираются из файлов в папках и не связаны с приходом.
- **Атаки:** `start = clamp(0.25×duration, 20, 60)`,
  `end = min(0.85×duration, duration−20)`; H2 **37,5–127,5 с**,
  H9 **60–306 с**.
- **Визуал:** `TemperatureGauge` вместо 03:42 в меню-баре, `StressOverlay`
  (heat-модель, alpha-only шейдер без screen texture), пульс SLA, тряска
  панелей ≤2 px, `reduce_motion`, `UiMotion`, Lane B (drag/карточки/слоты),
  headless-safe.
- **Баланс:** `tests/SIM_BALANCE_REPORT.md` — **7 205 $**, полоса
  **6 982–8 500 $**, магазин **3 964 $ (44,9 %)**, **0/240** поражений,
  exit **0**; H2, H4 и H5 близко к −20 % (H2 −16,4 %, H4 −15,3 %, H5 −15,1 %).
- **Тесты:** полный набор + parse-check; `test_economy` и `test_save` в
  runner; точный счёт не фиксируется.
