# PEAK HOUR 97

**Платформа:** Web (HTML5, Godot 4.7.2)
**Жанр:** менеджмент / тайм-менеджмент, retro UI
**Длительность:** 9 игровых часов по 5 минут + подготовка между часами
**Язык:** русский
**Управление:** мышь и клавиатура
**Окно:** 1600×900, логический viewport 1280×720

## Короткое описание

1997 год. Ночная смена в узле файлового обмена. Принимайте пакеты,
отправляйте файлы клиентам, держите SLA — и не дайте атакам положить канал.

## Описание

Вы — дежурный оператор узла 7. В 03:42 на столе мигает приём: пакеты
приходят быстрее, чем вы успеваете разложить их по папкам. Клиенты присылают
запросы на конкретные файлы — имя и папку видно в карточке, так что искать
приходится по всему диску. Перетащите пакет в папку, найдите нужный файл,
прикрепите его к запросу, установите соединение и отправьте. В окне
соединения три бегунка — три попадания по очереди, и канал ваш. Промах
закрывает панель: придётся нажать «Соединиться» снова.

Смена длится девять игровых часов по пять минут. На старте **SLA 128/200**,
а каждый потерянный пакет бьёт по типу файла: текст 2, звук 4, фото 8,
видео 16. Первый час проходит без атак; дальше в узел лезут мусор, DDoS,
фишинг и шифровальщик — их нужно вовремя заметить и уничтожить. Магазин
открывается после первого часа: **10 улучшений** от слотов и буфера до зоны,
канала, щита и запаса SLA. Поиск и щит открываются мета-прогрессом после
3-го и 5-го часа, продвинутые мини-игры — после 9-го (контент пока
в разработке). Дожить до конца смены — победа; уронить SLA — поражение.

Интерфейс вдохновлён Kaleidos: тёплая бумага, тонкие 1 px контуры, мягкие
тени и бирюзовый акцент. В первом часе рядом подсказывает маскот **БАЙТ**.
UI рисуется кодом, без внешних текстур; Handjet держит плотный русский
текст, Press Start 2P — логотип и цифры. Звуки синтезированы скриптом
проекта. Собрано на Godot 4.7.2 для Web без threads:
игра запускается в браузере без COOP/COEP. Это играбельный джем-прототип
полного цикла: меню, подготовка, девять часов, итоги, магазин, пауза,
настройки, атаки, сохранение и мета-открытия.

## Управление

| Действие | Ввод |
| --- | --- |
| Выбор, меню, перетаскивание | ЛКМ |
| Контекстное меню | ПКМ |
| Пакет из «Приёма» → папка | drag&drop |
| Файл из папки → карточка запроса | drag&drop |
| Поиск по имени в текущей папке | после открытия «Поиска» |
| Мини-игра соединения: три попадания | ЛКМ или `Space` |
| Мини-игра подготовки: отправить | `Enter` |
| Пауза | `Esc` |
| Панель соединения: отмена | `Esc` |
