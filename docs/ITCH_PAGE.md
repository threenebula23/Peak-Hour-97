# PEAK HOUR 97

**Платформа:** Web (HTML5, Godot 4.7.2)
**Жанр:** менеджмент / тайм-менеджмент, retro 90s
**Длительность:** 9 игровых часов по 5 минут + подготовка между часами
**Язык:** русский
**Управление:** мышь и клавиатура

## Короткое описание

1997 год. Ночная смена в узле файлового обмена. Принимайте пакеты,
отправляйте файлы клиентам, держите SLA — и не дайте атакам положить канал.

## Описание

Вы — дежурный оператор узла 7. В 03:42 на столе мигает приём: пакеты
приходят быстрее, чем вы успеваете разложить их по папкам. Клиенты присылают
запросы на конкретные файлы — имя и папку видно в карточке, так что искать
приходится по всему диску. Перетащите пакет в папку, найдите нужный файл,
прикрепите его к запросу, установите соединение и отправьте. В окне
соединения три бегунка — три попадания по очереди, и канал ваш. Ошибка стоит
времени, а время в час пик стоит дороже всего.

Смена длится девять игровых часов по пять минут. С каждым часом пакеты идут
чаще, запросы становятся наглее, а канал забивается сильнее. В узел лезут
мусорные пакеты, DDoS, фишинг и шифровальщик: их нужно вовремя заметить и
уничтожить, иначе SLA тает. Между часами — короткая подготовка и магазин:
девять улучшений от дополнительных слотов и буфера до ширины зоны соединения,
канала и щита. Дожить до конца смены — победа; уронить SLA — поражение.

Всё оформлено как забытая программа 1997 года: серые фаски, гравировка,
пиксельные иконки и заголовки. Интерфейс рисуется кодом, без внешних текстур;
Handjet держит плотный русский текст, Press Start 2P — логотип и цифры. Звуки
синтезированы скриптом проекта, без сторонних сэмплов. Собрано на Godot 4.7.2
для Web без threads: игра запускается в браузере без COOP/COEP. Это играбельный
джем-прототип полного цикла: меню, подготовка, девять часов, итоги, магазин,
пауза, настройки, атаки и сохранение между часами.

## Как раскрыта тема

«Час пик» — не декорация: с каждым часом растёт поток пакетов и запросов, канал
забивается, а SLA становится пределом пропускной способности. Игрок держит
инфраструктуру города в самый напряжённый час, выбирая между приёмом и отправкой
на общих TCP-слотах. Узкое место — не экран, а канал, время и руки оператора.

## Управление

| Действие | Ввод |
| --- | --- |
| Выбор, меню, перетаскивание | ЛКМ |
| Контекстное меню | ПКМ |
| Пакет из «Приёма» → папка | drag&drop |
| Файл из папки → карточка запроса | drag&drop |
| Поиск по имени в текущей папке | после апгрейда «Поиск» |
| Мини-игра соединения: три попадания | ЛКМ или `Space` |
| Мини-игра подготовки: отправить | `Enter` |
| Пауза | `Esc` |
| Панель соединения: отмена | `Esc` |
