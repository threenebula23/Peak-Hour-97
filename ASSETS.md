# ASSETS — PEAK HOUR 97

Сторонние и собственные ассеты проекта. В репозитории только файлы с явной
лицензией, совместимой с джем-проектом и MIT-кодом.

| Поле | Значение |

| Оригинал | `art/fonts/source/Kechusilka-Regular-original.otf` — только для сверки, к игре не подключён |
| Источник | архив `kechusilka-regular.zip` (загрузка пользователя), внутри `kechusilka-Regular_1.otf` и два PNG-превью |
| Версия | Version 1.000; 16.09.2026; FontCreator 15 |
| SHA-256 (нормализованный) | `e296eca059c05886da25808170accf6004619850dcac14200046199be04e10c8` |
| SHA-256 (оригинал) | `3f666b9b04dcbbfcfe3a31256d99e807553c9dd2efa3f360cc14422599917d36` |
| Лицензия | **подтверждена владельцем проекта** (license confirmed by project owner). Файла лицензии в архиве нет, строк copyright/license в шрифте тоже нет — поэтому текст лицензии здесь не приводится и её название не угадывается |
| Кириллица | полная: все 66 букв (включая Ё/ё), все цифры |
| Нет глифов | `№` U+2116, `–` U+2013, `…` U+2026, `·` `×` `← → ↑ ↓` `≤ ≥` `§` `°` `€` `•` `©` `±` `≈` `−` — закрываются fallback-шрифтом |
| Fallback | `GolosText-VF.ttf` через `Font.fallbacks` в `Theme90.ui()` |
| Использование | `FONT_UI`, `Theme90.ui()`; `default_font` темы `art/fonts/ui_theme.tres` |

**Нормализация.** У исходника x-height `0.312 em` против `0.530 em` у Golos
Text: в одном кегле текст был бы на 40 % мельче, и шкала 11/13/17/26 поехала
бы во всех карточках. Шрифт пересобран скриптом
`art/fonts/normalize_kechusilka.py`:

- коэффициент `scale = 0.530 × 2048 / 640 = 1.696`;
- масштабируются контуры (`TransformPen`), `hmtx` (advance + lsb),
  `hhea`/`OS/2`/`head` и 150 значений `GPOS` — иначе кернинг стал бы на 40 %
  слабее;
- результат: x-height `0.5298 em`, cap `0.7422 em`, линия `15.16 px` против
  `15.60 px` у Golos при 13 px; ширина русских строк отличается от Golos
  в пределах ±6 %, поэтому вёрстку пересчитывать не пришлось;
- хинтов в исходнике нет (0 stem-операторов), потерь при пересборке нет;
- сборка воспроизводима: повторный запуск даёт тот же файл и тот же SHA-256.

Оригинал не удалён — он лежит в `art/fonts/source/` и в теме не используется:
это точка сверки, если понадобится поменять коэффициент.

**Вес штриха.** Kechusilka светлее прежнего Golos Text `wght 600`: толщина
стойки `0.10 em` против `0.145 em`, то есть 1.35 px против 1.88 px при 13 px
(замер по растеризации `l`/`I`). На 11–13 px это читается, но на 9 px стойка
уходит в 0.94 px и текст «сереет». Поэтому подписи мельче 11 px лучше поднять
до `FS_MICRO`. Если после первого запуска в Godot захочется веса ближе к
прежнему, это делается одной строкой — `FontVariation.variation_embolden` в
`Theme90.ui()`; значение подбирать на месте, начиная с 0.1, потому что
масштаб эффекта зависит от версии TextServer.

### Kechusilka: чем закрыты отсутствующие символы

В шрифте нет 19 символов, которые встречаются в тексте проекта. Цепочка
`Kechusilka → Golos Text` закрывает все, кроме трёх: `Σ` U+03A3, `↔` U+2194
(только комментарии и тесты, на экран не попадают) и `▯` U+25AF — его нет ни в
одном шрифте проекта, включая прежний Golos, поэтому он и раньше рисовался
встроенным резервом Godot. Регрессии нет.

Проверено разбором `cmap` всех шрифтов проекта и всех строковых литералов
`.gd`/`.json`/`.tscn`, плюс рендер-симуляция подстановки: на 11–13 px стык
шрифтов не виден, потому что у Kechusilka и Golos совпадает x-height.

Условия лицензии, которые нужно соблюдать: файл распространяется «как есть» —
не переконвертировать в TTF, не сабсетить и не менять состав знаков без
разрешения автора; продавать шрифт отдельно нельзя.

### Совместимость лицензий

Golos Text, Handjet, Press Start 2P и Pixelify Sans — **SIL OFL 1.1**.
OFL разрешает встраивать шрифты в игру (включая коммерческую), но требует
сохранять текст лицензии и не продавать шрифт отдельно. Для производных
шрифтов действует Reserved Font Name. Это совместимо с MIT-лицензией кода:
MIT не накладывает ограничений на шрифты, а OFL-тексты лежат рядом с файлами.

DisplayOTF — **freeware**, не OFL. Играть и встраивать в игру можно, текст
соглашения лежит рядом (`LICENSE-DisplayOTF.txt`); продавать сам шрифт
отдельно и менять состав знаков нельзя. Это не мешает MIT-коду игры, но при
смене лицензии проекта или платной сборке условия нужно перечитать.

Kechusilka — по шрифту лицензия **подтверждена владельцем проекта** (license
confirmed by project owner). Текста лицензии в архиве и в файле шрифта нет,
поэтому её название здесь не указано и условия не пересказываются: если
проект будет публиковаться или продаваться, текст нужно запросить у
владельца. Нормализация (масштаб контуров) — техническое изменение файла,
о котором владелец уведомлён.

### Пиксельные иконки файлов

`art/icons/` содержит `file_text.png`, `file_sound.png`, `file_photo.png`,
`file_video.png`, `folder.png` и `packet.png` (все 32×32 RGBA). Иконки
показываются в сетке папки, drag-preview, чипах запроса и карточках пакетов;
в `Theme90.draw_file_icon()` они рисуются с `nearest`, поэтому остаются
резкими в 16/24/32 px.

- Генератор: `art/icons/generate_icons.py` (Python 3 + Pillow), палитра
  Kaleidos, контур 1 px `#2C2A26`, без сглаживания.
- Лицензия: **MIT**, сгенерировано в команде проекта в стиле пиксельного
  тайл-листа; сторонних спрайтов нет.
- Исходный тайл-лист/лист иконок был недоступен, поэтому набор **не вырезан**
  из готового файла, а **перегенерирован** скриптом с нуля. Это позволяет
  воспроизвести все PNG одной командой и не зависит от потерянного исходника.

Пересборка:

```bash
cd peak-hour
python3 art/icons/generate_icons.py
# превью: python3 art/icons/generate_icons.py --preview /tmp/opencode/icons_preview.png
```

`art/ui/` по-прежнему пуст (`.gitkeep`): отдельных UI-спрайтов нет.

## Аудио

Все звуки — оригинальные, синтезированы скриптом проекта
`audio/generate_sfx.py` (только стандартная библиотека Python, без сэмплов).
Автор — команда проекта, лицензия **MIT/CC0**: файлы можно свободно
использовать и распространять, скрипт — по MIT.

| Категория | Файлы |
| --- | --- |
| Интерфейс | `click`, `drag`, `drop`, `drop_error` |
| Приём и передача | `recv`, `request_ready`, `modem`, `connect_fail`, `tick`, `packet_loss` |
| Мини-игры | `minigame_win`, `minigame_fail` |
| Атаки | `attack`, `attack_blocked` |

22050 Гц, 16 бит, моно, пик −6 dBFS; SFX 30–800 мс. Сиды фиксированы, поэтому
повторная генерация даёт те же файлы.

## Как воспроизвести ассеты

### Звук

```bash
cd peak-hour
python3 audio/generate_sfx.py
```

Скрипт создаёт `audio/sfx/*.wav` (18 файлов) и `audio/music/hum.wav`, проверяет
длительности, пики и шов петли. Нужен только Python 3.

### Шрифты

```bash
cd peak-hour/art/fonts
# Golos Text: скачайте GolosText[wght].ttf из google/fonts/ofl/golostext
# и сохраните локально как GolosText-VF.ttf
curl -L -o PressStart2P-Regular.ttf \
  "https://raw.githubusercontent.com/google/fonts/main/ofl/pressstart2p/PressStart2P-Regular.ttf"
sha256sum GolosText-VF.ttf PressStart2P-Regular.ttf
# Kechusilka пересобирается из оригинала (нужен fontTools):
python3 normalize_kechusilka.py
```

Ожидаемые хеши — в таблицах выше. Тексты OFL уже лежат в `art/fonts/`; при
обновлении шрифта обновите и их. Handjet и Pixelify Sans для сборки не
требуются.

DisplayOTF уже лежит в `art/fonts/` вместе с лицензией — публичной ссылки на
него нет, файл нужно сохранять как есть (не переконвертировать в TTF и не
сабсетить).

Kechusilka тоже в репозитории: `Kechusilka-Regular.otf` — результат
нормализации, оригинал лежит в `art/fonts/source/`. Правьте не результат, а
скрипт: он пересобирает файл из оригинала и даёт тот же SHA-256. Если
пересобрали — обновите хеш в таблице выше.

### Графика

Иконки пересобираются `python3 art/icons/generate_icons.py` (нужен Pillow).
`icon.svg` — обычный SVG. После клонирования достаточно импортировать проект
в Godot 4.7.2.

## Чего в проекте нет
